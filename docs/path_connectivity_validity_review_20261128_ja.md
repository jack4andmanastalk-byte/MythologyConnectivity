# グラフのパス接続性はどの程度「有効」か — 現状の解説（2026-11-28）

対象: 本リポジトリの埋め込みグラフ（v17 凍結 HTML、297 ノード / 597 エッジ）と、それを用いた
パス・接続性に関する記述（`docs/v18_method_and_results.md` §7、`docs/interactive_graph_html_ja.md`、
`docs/v17_integrity_verification_report.md`、`docs/v17_network_attachment_verification_20261127_ja.md`、
`docs/registry.md`）およびデータ群（`derived/v17_html_embedded_data.json`、`data/frozen/*`、
`derived/html_embedded_v17_audit.json`）。

本書は**新しい仮説の検定ではない**（`docs/registry.md` への枝の追加は行っていない）。既存の
検証済み数値と、凍結データから再計算できる記述統計を突き合わせ、「パスの接続性」という
主張が現状どこまで支えられているかを切り分けるための解説である。

---

## 0. 結論（要約）

| 主張の種類 | 現状の評価 | 根拠の所在 |
| :--- | :--- | :--- |
| (1) 297 ノード / 597 エッジのグラフとして**構造が健全**（DAG・参照切れ 0・自己ループ 0・重複 0） | **有効**（機械検証済み） | 検査 B1–B3, B7 / `registry.md` 枝 #3 |
| (2) **古事記ノードに到達するパスが存在する**（37/37 話が親を持つ、経路は分断されていない） | **有効**（ただし条件付き） | 本書 §2 の再計算（B19 の「弱連結 3 成分」の内訳もここで確定） |
| (3) そのパスが**西ユーラシアにまで遡る**（メソポタミア・エジプト・ギリシャ・インド等） | **弱い（間接的・1 本の鎖に依存しうる）** | §3。直接流入は 0 本、すべて 2 ホップ以上の中継 |
| (4) 個々のエッジ（＝パスの各辺）が**データから再現できる** | **部分的（全体 61% / 古事記流入辺 33%）** | §4。凍結行列からの再計算 |
| (5) ノードに表示される**被説明率（パスの説明力）**が画面のエッジから導ける | **古事記 37 話では導けない**（表示は 3 層分解由来）。乖離 21 話 | `derived/html_embedded_v17_audit.json` / ADR 0003 |
| (6) 「構造がある」ことの**統計的有意性** | **有効**（全 281 ノードで p = 0.005） | 検査 E-cosine / E-calibrated、§7 表 8 |
| (7) 「**最長の伝播経路 8,451 km**」等の長距離接続の記述 | **距離・重みとも再計算できるが、古事記への経路ではない** | §5 |
| (8) 第 2 層（王権・儀礼・レガリア 15 次元）の**パスとしての意味** | **情報を認めない**（p = 0.498、d = −0.04） | `v18_method_and_results.md` §4.2、`registry.md` #1 |

**一言で言えば**: 「グラフとしての骨格と到達可能性」は有効だが、「個々のパスが何を意味するか」は
部分的にしか有効でない。とくに (a) 古事記へ流入する 126 本のうち凍結 75 次元行列から重みを
再現できるのは 42 本（33%）にとどまる、(b) 西ユーラシアへの接続はすべて中継ノード経由（直接辺 0 本）で、
中継ノードの辺の再現性に依存する、(c) ノードに表示される被説明率は画面のエッジから
再計算できない、という 3 点が「パスの有効性」の上限を決めている。

## 1. 前提: どのパスを「接続性」と呼んでいるか

リポジトリには方向の異なる 2 つの「経路」概念があり、混同すると評価を誤る。

| 層 | 実体 | データ | 意味 |
| :--- | :--- | :--- | :--- |
| **A. 可能性の層** | 交易路オーバーレイ 12 ルート | `data/trade_routes.json` | 物品・情報が**移動可能だった**ことの近似。解析計算には未使用（表示専用） |
| **B. 実証の層** | モチーフ伝播グラフ 597 エッジ | `derived/v17_html_embedded_data.json` | モチーフの**共有**が記録された辺。`source → target` は「先行 → 後行」 |

`docs/interactive_graph_html_ja.md` は A を「可能性のレイヤー」、B を「実際に移動した情報の実証層」と
位置づけている。「パスの接続性の有効性」を問う場合、A は交易史学の知見の近似（本リポジトリの
検証対象外）、B が本題である。以下 B のみを扱う。

なお B には 4 つの層ラベルが混在する（検査 C2）: `L1_myth` 489 / `L2_ext` 85 / `L2_dom` 18 / `L1+L2` 5。
パスの意味は「どの層の辺を辿ったか」で変わる。

## 2. 有効な部分 — 到達可能性と構造

凍結埋め込みデータ（`derived/v17_html_embedded_data.json`、原本 SHA-256 照合済み）から再計算した。

| 指標 | 値 | 解釈 |
| :--- | ---: | :--- |
| 弱連結成分 | 3（295 + 孤立 2） | 実質 1 つの連結グラフ。孤立は `NO07` / `EX16`（検査 B19 と一致） |
| 自己ループ / 重複 / 参照切れ | 0 / 0 / 0 | 健全（B1–B3） |
| DAG（Kahn 整列） | 297 / 297 | 全ノードが整列可能。時間逆行辺 0（`t_eff` 差と `dt` も全 597 本で一致） |
| 古事記 37 話の親（入辺） | 126 本（`external` 110 + `LP` 16） | **37 話すべてが 1 本以上**の親を持つ（入次数 1–6、中央値 3） |
| 古事記からの出辺 | **0 本** | 「古事記は親になれない」規則のとおり（検査 B21） |
| 根（入次数 0） | 31 | パスの始点候補 |
| 最長パス（有向） | 17 エッジ | 例: `MS_U02`(前2400) → … → `K1-05`(712)（メソポタミア→インド→イラン→仏教→ステップ→朝鮮→シベリア→古事記） |
| 古事記 37 話の祖先集合 | 中央値 53（最小 2 / 最大 88） | 1 話あたり中央値 53 ノードが「先行文脈」として繋がっている |
| 古事記の祖先集合の和 | 141 / 297 ノード | パスの上流は全ノードの約 47% を覆う |
| 全 597 本のうち古事記への祖先パス上にある辺 | 352 本 | グラフの約 59% が古事記に至る経路上 |
| 古事記集合とその他を分かつ**辺連結度** | 126 | 1 本の辺を切っても分断されない（冗長な接続） |
| 西ユーラシア地域と古事記の**辺連結度** | 53 | 同様に冗長。ただし後述の「鎖依存」は経路の**意味**の話 |

**ここまでは有効である。** 「古事記 37 話が、ユーラシアの神話ノード群からなるグラフに
到達可能な形で接続されている」ことは、構造検査と独立再計算の両方で確認できる。
検査 B19 が `warn`（弱連結 3 成分・孤立 2）としているのも、この 2 ノードが孤立しているだけで、
連結性の実質的な欠陥ではない。

### 2.1 ただし「密な接続」の見かけには注意（探索的・未登録）

以下は登録外の参考計算であり、判定には使わない。

- 古事記 37 話の祖先集合は中央値 53 ノード。しかし、**同じ入次数を保ったまま、リポジトリ自身の
  時空間適格判定（`src/engine.build_eligibility`）の範囲で親をランダムに選び直す**と、
  祖先集合の中央値は 34.4 ± 5.0（200 回）になる。観測値 53 はこの帰無分布の 100 百分位にある。
- つまり「祖先が多い」こと自体は、**グラフの次数構造と時空間ゲートからある程度自動的に出る**
  量ではなく、観測値の方が明確に大きい。この方向の「到達可能性の豊かさ」はデータ固有である。
- 一方で、これは**モチーフの意味的対応の証拠ではない**。同じ手続きを「再現可能な辺のみ」に
  制限すると、観測値は中央値 7、帰無は 7.3 ± 1.6（36 百分位）となり、差は消える（§4 参照）。

## 3. 弱い部分 — 「西ユーラシアまで遡る」は中継に依存する

`docs/interactive_graph_html_ja.md` の考察は「古事記以前にユーラシア東端から西端まで
リレー式の接続が成立していた」と述べ、その傍証としてモチーフ伝播グラフの長距離辺を挙げる。
この主張の**グラフ側の強さ**は次のように整理できる。

| 事実（597 本の再計算） | 値 |
| :--- | ---: |
| メソポタミア・エジプト・ギリシャ・インド・アナトリア・イラン → **古事記への直接辺** | **0 本** |
| 古事記への直接の流入元の地域 | シベリア 33 / 中国 27 / 朝鮮 27 / 東南アジア 19 / 列島前史 13 / ステップ 7 |
| 西ユーラシア（上記 6 地域）から古事記集合への経路長 | 最短 2 ホップ（29 話）、3 ホップ（7 話）、経路なし（1 話 = `K1-18`） |
| 西ユーラシア発で古事記の祖先パス上にある辺 | 146 本 / 597 |
| 古事記の祖先集合に含まれる西ユーラシア・ノード | メソポタミア 30 / インド 24 / エジプト 9 / イラン 5 / ギリシャ 3 / アナトリア 2（延べ） |

つまり **古事記と西ユーラシアの接続は、すべて「シベリア・中国・朝鮮・東南アジア」など
中間地域のノードを経由した 2〜3 ホップの中継**である。これは異常ではない
（地理的距離と時間差を考えれば自然な形）が、次の 2 つの帰結を持つ。

1. **経路の有効性は中継ノードの辺の質に依存する。** 西→古事記の直接証拠ではなく、
   「西→中継」「中継→古事記」の 2 本の辺がそれぞれ妥当かで決まる。
2. **中継ノードを 1 つ外すと経路が消える場合がある。** 無向グラフの橋（bridge）は 26 本あり、
   そのうち 3 本（`SE01–K1-08`、`SI12–K1-22`、`SE02–K1-18`）は**片側に古事記ノードが 1 つだけ**
   乗っている。この 3 話は、その 1 本の辺が妥当でなければ上流全体への接続を失う。
   `K1-18`（木花之佐久夜毘売と石長比売）は、西ユーラシアへの経路を持たない唯一の話である。

また、`docs/interactive_graph_html_ja.md` が例示する古事記への親エッジは、
**重みがデータから再現できる辺**（§4 参照）と、そうでない辺が混在している。

| 例（同書の記載） | 距離 | Δt | 表示重み | 75D 行列からの再計算コサイン | 一致 |
| :--- | ---: | ---: | ---: | ---: | :---: |
| `CN04 → K1-02` | 2,982 km | 512 年 | 0.949 | 0.949 | ○ |
| `SE08 → K1-01` | 4,078 km | 512 年 | 0.667 | 0.667 | ○ |
| `SI09 → K1-01` | 4,474 km | 1,212 年 | 0.370 | **0.667** | × |

`SI09 → K1-01` は「シベリア→K1-01（4,474km・Δt=1,212年）」の例として引かれているが、
表示重み 0.370 は原文行列のコサイン 0.667 と一致しない（差 0.297）。
`tests/test_interactive_html.py` は**距離と Δt のみ**を照合しており、重みの再現性は検査していない。

## 4. 「辺の再現性」の実測 — ここが最大の制約

`docs/v18_method_and_results.md` §7 は「独立実装が描く辺は v16 の 494 本と 255 本しか重ならない
（Jaccard 0.349）」と報告している。本節はそれを**辺の種類別**に分解したものである
（凍結 `data/frozen/l1_75d_legacy_matrix.csv`（281×75、非零 1,500 セル）から再計算）。

### 4.1 全体

| 比較 | 値 |
| :--- | ---: |
| 両端が L1 行列に含まれる表示エッジ | 533 / 597 |
| うち 表示重み = 生コサイン（±5e-4） | **312（58.5%）** |
| うち 表示重み = 生コサイン（±0.01） | 325（61.0%） |
| うち 表示重みとコサインが 0.1 以上ずれる | **142（26.6%）** |
| 重み > 0 なのにコサイン = 0（＝特徴量の共有が 1 次元もない） | **18 本（すべて古事記への流入辺）** |
| 各ターゲットの最大重み辺（第 1 ステップ相当、249 本）のうち ±5e-4 で一致 | 205（82%） |

### 4.1b 剥離ステップ別の一致率（重みの順位をステップの代理指標にした記述統計）

埋め込みデータには剥離ステップ番号が無いため、ターゲットごとに重み降順の順位で近似した。

| 重み順位（ステップの代理） | 辺数 | 重みとコサインが 0.1 以上ずれる | 不一致率 |
| :--- | ---: | ---: | ---: |
| 1 | 249 | 21 | 8% |
| 2 | 181 | 67 | 37% |
| 3 | 85 | 44 | 52% |
| 4 以上 | 18 | 10 | 56% |

**第 1 ステップに相当する辺はほぼ再現し、2 ステップ目以降は再現しない**という明確な勾配がある。
v17 の被説明率は 3 親までの貪欲剥離で計算されるため、**上流の 2・3 本目の辺が再現しないことは
最終的な被説明率の再現性に直結する**（検査 D2/D3 の乖離と同じ方向）。

### 4.2 古事記への流入辺に限った内訳（最重要）

| 区分 | 本数 | 備考 |
| :--- | ---: | :--- |
| 古事記への流入辺 合計 | 126 | `external` 110 + `LP` 16 |
| うち L1 行列の両端が揃い、重み = 生コサイン（±0.01） | **42** | 検証可能 |
| うち上記以外（重みがコサインで説明できない／LP 起点の L2 辺） | **68 + 16 = 84** | 再計算不能 |
| **再現可能率** | **33%（42/126）** | |

すなわち、**古事記の「先行被説明率」を支えるパスの辺のうち、約 3 分の 2 は凍結行列から
独立に再現できない**。これは不正の証拠ではない（v17 のエッジは剥離エンジンの 2 ステップ目以降や
L2 層の寄与を含むため、単純な生コサイン一致を期待できない設計になっている）。
しかし「パスが何を根拠に描かれているか」を外部の読者が検証できる範囲は、この 3 分の 1 に限られる。

### 4.3 「再現可能な辺だけ」に絞ると何が残るか

表示エッジのうち、①重みが生コサインで再現できる L1 内部辺、②LP 起点の L2 辺（生成規則 C1 で
仕様として説明済み）だけを残すと **369 本（62%）** になる。この部分グラフでは:

| 指標 | 全 597 本 | 再現可能 369 本のみ |
| :--- | ---: | ---: |
| 古事記 37 話の祖先集合 中央値 | 53 | **7** |
| 西ユーラシア祖先を持つ話 | 36 / 37 | 31 / 37 |
| 祖先集合の帰無分布（同次数・時空間適格）に対する百分位 | 100% | **36%（差なし）** |
| 古事記への流入辺 | 126 | **58**（うち `LP` 由来 16）。37 / 37 話が 1 本以上を保持 |

**解釈**: 「祖先が多い／接続が豊か」という見かけは、**再現性の低い辺が担っている**。
再現可能な辺だけでは、接続の豊かさは同次数ランダムグラフと区別できない。
これは §7 表 8 の「構造は再現するが個々の辺は実装依存」という結論を、接続性の側から
具体的に裏づける結果である（参考計算・未登録）。

## 5. 「最長伝播距離 8,451 km」等の記述の位置づけ

`docs/interactive_graph_html_ja.md` は最長エッジ `IN_B07 → NO13`（8,451 km、Δt 1,000 年、重み 0.416）と、
6,000 km 超が 22 本あることを挙げ、実際の移動の証拠としている。データ上の値は正しく、
**重みも独立再計算できる**（凍結 75 次元行列のコサイン 0.4161、差 0.0001）。

| 確認項目 | 結果 |
| :--- | :--- |
| 最長エッジ `IN_B07 → NO13` の端点が L1 行列に含まれるか | 両方含まれる（再計算可） |
| その重みの再現 | 0.416 対 コサイン 0.4161（一致） |
| 6,000 km 超の 22 本のうち重みが再現できるもの | 18 / 22（4 本は 0.1 以上ずれる） |
| この辺は古事記への経路か | **いいえ**。インド（仏教）→ 北欧・ケルトの辺で、古事記ノードは端点でない |

したがって「8,451 km の辺が存在する」ことは有効な記述だが、これは**古事記への接続の証拠ではない**
（古事記へ流入する 126 本の辺の中央値は 1,596 km、最大は `ST_E01 → K2-05` の 6,056 km。例示されている 4,474 km は上位に入る長い辺である）。§3 のとおり、
古事記と西ユーラシアの接続は中継ノード経由の短い辺の連鎖で構成されている。

## 6. 表示される「パスの説明力」— 画面からは再計算できない

`derived/html_embedded_v17_audit.json`（ADR 0003）が示すとおり、ノードの `explained_pct` は
3 系統の混成である。

| 出所 | ノード数 | 内容 |
| :--- | ---: | :--- |
| `v16.L1` | 244 | v16 単層の剥離値 |
| `decomp.total_final` | 37 | 3 層分解（L1 + L2ext + L2dom）の合成値。**古事記 37 話** |
| `pureL2_dom` | 16 | 純第 2 層の剥離値（LP13–16 等） |

古事記 37 話はすべて `decomp.total_final` であり、画面に描かれている L1 エッジから
再計算した値とは 21 話で 0.01 以上ずれる（最大は `K1-05`: 表示 0.707 対 再計算 0.2332、差 −0.4738）。
**「このパスでこの話の 70.7% が説明される」と画面から読むことはできない。**
この点は ADR 0003 で「凍結原本は改変せず、台帳と注記で運用する」と決定済みであり、
`docs/interactive/graph_network_atlas.html` には乖離バッジと注記が実装されている
（`make interactive` で再生成してもバイト単位で同一であることを本日確認）。

統計的な位置づけも併記しておく。第 2 層（15 次元）の主検定は p = 0.498、効果量 d = −0.04、
FDR 有意 0 / 25 話であり、**「パスが王権・儀礼・レガリアのモチーフを偶然以上に説明する」
という主張は支持されない**（`registry.md` #1、#7）。第 1 層（75 次元）は p = 0.005、d = 5.61 で
陽性対照として成立している（同 #2）。

## 9. 「パスの接続性」を引用するときの推奨表現

現状の証拠に忠実な言い方に直すと、次のようになる。

> 凍結グラフは 297 ノード / 597 エッジの非巡回 DAG で、古事記 37 話はいずれも 1 本以上の先行辺を
> 持ち、中央値 53 ノードの祖先集合を介してユーラシアの神話ノード群に到達可能である。
> 全体の 281 ノードを対象とした順列検定は p = 0.005 で、「偶然では説明できない構造がある」ことは
> 支持される。ただし、古事記へ流入する 126 本の辺のうち凍結 75 次元行列から重みを再現できるのは
> 約 3 分の 1 であり、西ユーラシアへの接続はすべて中間地域を経由した 2〜3 ホップの中継である。
> 再現可能な辺のみに制限すると、祖先集合の規模は同次数のランダムグラフと区別できなくなる。
> また、画面に表示される被説明率は 3 系統の混成で、古事記 37 話では画面のエッジから再計算できない
> （21 話で 0.01 超の乖離）。第 2 層（王権・儀礼・レガリア）については、事前登録した検定で
> 情報を認めない（p = 0.498、d = −0.04）。

避けるべき表現:

- 「85% のモチーフがユーラシア起源だとグラフが示す」→ 表示値は 3 層分解の合成で、画面の
  エッジからは導けない。かつ第 2 層は帰無と区別できない（`v18` §4.2）。
- 「8,451 km の伝播経路で古事記まで繋がっている」→ 最長辺の終点は北欧 `NO13` であり、
  古事記へは届かない。古事記に至る経路の辺はすべて中継地域との間の辺で、
  古事記への流入辺の距離は中央値 1,596 km である。
- 「52 話」→ 凍結データは 37 話。
