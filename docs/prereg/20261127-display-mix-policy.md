# 事前登録・運用方針固定: 表示混成 21 話の扱い（タスク B）

登録日: 2026-11-27
状態: 仕様変更前に固定（本ファイルのコミット時刻が証拠）
関連 ADR: `docs/adr/0003-display-mix-policy.md`
関連登録簿: `docs/registry.md`（枝 ID: `NET-DISPLAY-21`）

## 背景と問い

`src/verify_network.py`（枝 `NET-597`）により、v17 インタラクティブ HTML に埋め込まれた
297 ノード / 597 エッジのグラフは生成規則まで再現可能である一方、ノードの被説明率
`explained_pct` の出所が 3 系統（v16 L1 / 3 層分解 / 純 L2）に混成しており、
画面上のエッジから再計算した値と 21 / 248 ノード（すべて古事記）で 0.01 超の乖離があることが判明している。

## 採択方針（作業実施前に固定）

1. **凍結された v17 HTML 本体および `vendor/` は改変しない。**
   * v17 HTML は過去の検証対象（凍結原本）であり、かつ `.gitignore` により大型 HTML は追跡しない方針（ADR 0001 §4）である。
   * v17 側の値を書き換えて乖離を隠すのではなく、**注記＋機械的出所台帳による運用**を採る。
2. **ADR 0001 §4 に基づき、`derived/` 配下に機械可読な注記・監査データを保持する。**
   * `derived/html_embedded_v17_audit.json` に、全 297 ノードの出所（`provenance`）と、乖離 21 話の個別の表示値・L1 再計算値・差分・仕様注記を抽出・保存する。
3. **`src/verify_network.py` に不変条件検査を追加し、CI で継続監視する。**
   * v17 実データから再計算される混成 21 話の集合・数値が `derived/html_embedded_v17_audit.json` と一致すること（不整合 0 件）。
   * すべての乖離ノードに明示的な `provenance` と注記が付与されていること。

## 判定基準（整合性検査）

* 混成ノード数の期待値（21 話 / 248 評価対象）および乖離ノード ID 集合が機械検査と完全一致すること。
* `vendor/` が存在する環境での `verify_network.py` 実行時に不整合（`ng`）が 0 件であること。
* 注記・数値が `src/verify_doc.py` の照合対象として自動検証されること。
