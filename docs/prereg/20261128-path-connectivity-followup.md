## 背景

2026-11-28 のレビューで、パス接続性の有効性を「構造」「辺の再現性」「中継依存」「表示値の
再現性」「文書数値の整合」の 5 軸に分解した。うち 4 軸は**現状の出力に機械的な列が無い**ため
手作業の再計算に頼っていた。本登録は、その 4 軸を決定論的なパイプライン出力にする計画と、
**結果を見る前に固定する判定規則**を定める。

いずれも**仮説検定ではなく整合性検査**（`docs/registry.md` の種別「整合性検査」）である。
したがって Holm 補正の対象枝数には数えない（`src/check_registry.py` の
`HYPOTHESIS_KIND == "仮説検定"` の定義どおり）。

## 検証 1（枝 #8 `NET-EDGE-REPRO`）: エッジ再現性の全件分類

**対象**: `derived/v17_html_embedded_data.json` の 597 エッジ、`data/frozen/l1_75d_legacy_matrix.csv`。

**分類規則（固定）**: 各エッジを次の 4 クラスのいずれか 1 つに割り当てる。

| クラス | 規則（上から順に評価） |
| :--- | :--- |
| `l1_cosine` | 両端が凍結 L1 行列に存在し、`abs(weight − 生コサイン) <= weight_rounding` |
| `l1_mismatch` | 両端が凍結 L1 行列に存在し、上記を満たさない |
| `l2_construction_rule` | source が `LP`（第 2 層の生成規則 C1/C2 で説明される辺） |
| `unverifiable` | 上記以外（凍結行列に端点が無く、規則でも説明されない） |

**許容差**: `config/analysis.json` の `network.tolerances.weight_rounding`（= 0.0005）を主系とし、
0.01 を感度系として併記する。しきい値をコードに書かない。

**合格条件（機械）**: 出力 `outputs/edge_reproduction.csv` の行数 = 597、
クラス合計 = 597、各クラスの件数を `outputs/edge_reproduction.json` に記録。
古事記流入辺（`target` が `kind=kojiki`）の内訳を別掲する。

**判定の書き方**: 再現率は**記述統計として報告**し、「再現しない＝誤り」とは書かない。
再現しない辺が剥離の 2 段目以降に偏るかどうかも併記する（順位は重み降順で近似）。

## 検証 2（枝 #9 `NET-PATH-DEP`）: 中継ノード依存（1 ノード除去アブレーション）

**対象**: 同上の DAG。

**手続き（固定）**: 各ノード `u` を 1 つずつ除去し（入射辺も除去）、古事記 37 話それぞれについて

1. 祖先集合が空になるか（＝上流との接続喪失）
2. 祖先数が中央値の 50% 未満に落ちるか
3. **厳格な西ユーラシア祖先**（メソポタミア 3 層・エジプト 2 層・ギリシャ・ローマ・アナトリア・
   レヴァント・イラン・インド 3 系統）を失うか

を再計算する。除去ノードは「古事記の祖先集合に含まれるノード」に限る（それ以外は定義上無影響）。

**合格条件（機械）**: 出力 `outputs/path_dependency.json` に、影響のあるノードと
影響を受ける話数の一覧、および全 37 話の到達不能化件数（0 件であること）を記録する。
無向橋（bridge）と関節点（articulation point）も併記し、`K1-18` の西ユーラシア経路なしを
既知の例外として明示する。

**判定の書き方**: 「除去で到達不能になる話が 1 件でもあれば、そのノードは単一障害点」と書く。
0 件なら「単一障害点は無い」と書き、**辺**単位の橋（26 本）とは区別する。

## 検証 3（枝 #10 `NET-DISPLAY-REPRO`）: 表示被説明率の再計算可否の機械列

**対象**: `derived/html_embedded_v17_audit.json`（297 ノードの出所台帳）。

**手続き（固定）**: 各ノードについて

* `replay_l1` が記録されているか（＝画面の L1 エッジから再計算できるか）
* `abs(displayed_pct − replay_l1)` が `display_policy.gap_threshold`（= 0.01）を超えるか
* 出所（`v16.L1` / `decomp.total_final` / `pureL2_dom`）

を列として出力し、出所別・`kind` 別（古事記 / 欧州 / アンカー）に集計する。

**合格条件（機械）**: 出力 `derived/display_reproducibility.json` と
`outputs/display_reproducibility.csv` の総数 = 297、`gap` 判定数が
`display_policy.expected_gap_nodes`（= 21）と一致すること。既存の検査 F10 と同じ値で
あることを機械照合する。**凍結 HTML は改変しない**（ADR 0003 の不変条件）。

**判定の書き方**: 「再計算できないノードがある」ことは**仕様**（3 層分解の表示）であり、
欠陥ではない。問題は「画面から再現できるかの表示が無いこと」なので、列を追加したうえで
HTML の注記カードに反映する。

## 検証 4（枝 #11 `DOC-NUMBER-CONSISTENCY`）: 文書数値の整合ゲート

**対象**: `docs/` 配下の Markdown と `derived/`・`data/frozen/`。

**規則（固定）**:

1. **古事記ノード数**: 定義値を `data/frozen/nodes_297.csv` の `kind == "kojiki"` の件数とする
   （現在 37）。文書中で「古事記 N 話」「古事記 N ノード」と書く場合、N は定義値と一致すること。
   `startswith("K")` による件数（`K1-`〜`K3-` + `KR`）を古事記の話数として書かない。
2. **検査項目数**: 定義値を `docs/v17_network_attachment_verification_20261127_ja.md` の
   検査表の行数（ID 列が英字+数字で始まる行）とする（現在 60）。
   「検査 N 項目」「N チェック」「全 N 項目」の N は定義値と一致すること。
3. **登録枝数**: `docs/registry.md` の実測（`src/check_registry.py` と同じ計数）と、
   「全 N 枝」の N が一致すること。
4. **ネットワーク件数**: `derived/v17_html_embedded_data.json` のノード数・エッジ数（297 / 597）。

**合格条件（機械）**: `src/verify_numbers.py` が違反 0 件で exit 0。1 件でもあれば exit 1 とし、
`make all` と CI を落とす。許可する表記の一覧は設定 `config/analysis.json` の
`doc_checks` に置く（コードに文字列を書かない）。
例外は「歴史的記録として当時の値を引用する箇所」で、行末に `<!-- doc-number-exempt -->`
を付けた行に限る（凍結された過去レポートの引用を壊さないため）。
