# 事前登録: 語彙変更を伴う独立第3者評定 pass C の信頼性と感度検証（タスク C）

登録日: 2026-11-27
状態: 評定・実行前に固定（本ファイルのコミット時刻が証拠）
関連登録簿: `docs/registry.md`（枝 ID: `L2-PASSC-INDEP`, `L2-PASSC-SENS`）

## 目的

pass A と pass B の一致度（555 セル計算で α = 0.755、二重評定 13 話・195 セル上では α = 0.954）は、
**同一語彙定義**のもとでの再現性であり、語彙名に含まれる固有名詞や歴史的例示
（例: 草薙・アキナケス・三種神器・出雲大社など）による誘導共有バイアスを除去できていない。
本事前登録は、語彙定義を中立的な一般操作定義に置き換えた独立第3者評定（pass C）により、
評定一致度の低下量と結論の頑健性を測定する。

## 対象集合と独立性条件

1. **対象 13 話**: 二重評定（pass B）と同一の 13 話
   `K1-05, K1-07, K1-09, K1-12, K1-16, K1-17, K2-01, K2-04, K2-08, K2-09, K2-11, K3-01, K3-04`
   （規則 R7 に従い、同一 13 話・195 セル上で同一語彙時との比較を行う）。
2. **語彙の変更（`L2_ALT_V1`）**:
   * R01〜R15 の各次元から特定神話・地域・固有名詞の例示を削除し、
     比較宗教学・政治人類学の一般的な機能定義のみに書き換えた定義（`config/analysis.json` の
     `pass_c.alt_vocab_definitions` に固定）を使用する。
   * 本文に直接記述されていない後代制度や文献学的推測の外挿を行わない（厳格テキスト準拠）。
3. **ブラインドと証拠**:
   * pass A・pass B・v17 の水準値および 6 大仮説を参照せず（`blinded_to` に明記）、独立に 0〜3 で評定する。
   * 水準 > 0 の全セルに 6 文字以上の根拠記述（`evidence`）を必須とし、`src/validate.py` で検証する。

## 評価項目と判定基準（結果を見る前に固定）

### 枝 1: `L2-PASSC-INDEP`（信頼性測定）

* 同一 13 話（195 セル）において、Krippendorff α（順序尺度）、完全一致率、±1 以内一致率を
  pass A 対 pass C、pass B 対 pass C について算出する（参考として 37 話 0 埋め算出も併記）。
* 同一語彙での α（555 セル基準 0.755、同一 13 話 195 セル実測 0.954）からの低下量 Δα を算出する。
* **判定基準**: `alpha >= 0.667` を満たす場合「語彙変更下でも暫定許容水準の一致を維持」、
  `alpha < 0.667` の場合は「語彙依存性が大きく、単独語彙の結論の頑健性に限界がある」と判定する。

### 枝 2: `L2-PASSC-SENS`（仮説検定・感度確認）

* 全 37 話のうち上記 13 話の評定を pass C に差し替えた第2層プロファイル（他 24 話は pass A 維持）
  およびアンカー 16 件を用い、主系と同一のエンジン設定（`calibrated`, 次元シャッフル帰無）で
  主エンドポイント `mean_best_match_z` を再計算する。
* 登録枝数 N = 3（`L2-15D`, `L1-75D`, `L2-PASSC-SENS`）に対する Holm 補正後の第1しきい値
  （α / 3 = 0.0167、必要最小置換回数 59 ≤ 設定 `n_perm = 200`）を適用する。
* **判定基準**: 確定済み主系（`L2-15D`）は変更せず、本枝が事前登録条件（Holm 補正下での有意性、
  効果量 d ≥ 0.8、pass A-C 間 α ≥ 0.667）をすべて満たす場合のみ「語彙変更後でも信号あり」とし、
  1 つでも満たさなければ「第2層に情報を認めない（結論は語彙変更に対して不変）」と判定する。
