# 比較神話ネットワーク検証（v18 / v18.1）査読用サマリ（日本語 2 ページ要約）

**研究課題**: ユーラシア神話群 297 ノード（古事記 38 話＋比較地域・時代群）を対象とする先行計算パイプライン（v17）で報告された「第2層（王権・儀礼・レガリア 15 次元）の顕著な接続性・被説明率」が、構造的・テキスト的裏付けをもつ実質信号か、それとも計算仕様に由来する見かけの産物かを検証する。

**結論**:
1. **第2層（15 次元）には統計的情報を認めない**。帰無仮説を棄却できない（校正済み主指標 3.020 vs 帰無 3.024 ± 0.100, p = 0.498, 効果量 d = −0.04；先行 v17 値の順尺度変換でも 2.473 vs 2.470 ± 0.063, p = 0.502, d = 0.04）。
2. **解析装置自体は第1層（75 次元）陽性対照を強く検出する**。v16 由来の第1層ではコサイン系 p = 0.005（d = 13.83）、校正系 p = 0.005（d = 5.61）となり、第2層の無信号は検出感度不足ではなく当該層における信号欠如を示す。
3. **第2層の見かけの高被説明率は、評定基準・指標の飽和・類似度非校正の合成効果であった**。原文引用に基づく再評定、中立的操作定義 `pass C` への差し替え（p = 0.751, d = −0.65）、および登録制 Holm 補正（全 12 枝・仮説検定 3 枝、第 1 しきい値 0.0167）を通じても結論は一切変わらない。

---

## 1. 先行システム（v17）の構造監査と 21 話表示混成の確定

凍結された v17 対話式 HTML グラフ全 297 ノード・597 エッジ（4 種の検証コードと SHA256 で固定）を AST 定数抽出・再計算により全件監査した（`src/verify_network.py`: 全 60 項目中 OK 40 / WARN 7 / NG 0 / INFO 13）。

* **3 層構造の非整合**: HTML 表示グラフ 597 本は、報告書が論じる 90 次元同時推定グラフ 504 本と同一ではなく（共通 393 / 90 次元のみ 111 / 表示のみ 204）、v16 の第1層エッジに古事記・LP 周辺の第2層エッジを事後重畳した混成物であった。
* **表示被説明率の混成（ADR 0003 / 枝 #5）**: 評価可能 248 ノードのうち 21 話（すべて古事記 37 話内に所在）で、表示値と画面上の第1層エッジからの再計算値が 0.01 超乖離した（最大乖離 `K1-05`: 表示 0.707 vs 再計算 0.2332、差 −0.4738）。内訳を `derived/html_embedded_v17_audit.json` に全 297 ノード分（`v16.L1` 244 / `decomp.total_final` 37 / `pureL2_dom` 16）として台帳化し、凍結 HTML は改変せずチェック `F10`（21 / 21 話一致）で毎実行時に出所一致を保証する運用を確定した。

## 2. 再検証設計（v18 / v18.1）：ハーネス駆動型検証

手書きの重み行列・閾値・文書数値を排するため、全定数と語彙を `config/analysis.json` に集約し、全 12 スクリプト（`src/audit_no_hardcode.py` で許可外数値リテラル 0 を確認）で処理した。

* **根拠付き 4 段階順序尺度（0〜3）**: 非零のすべてのセルに最低 6 文字の原文引用を必須とし、`src/validate.py` が全 6 ファイル・137 レコード（`pass A` 37 話 + アンカー 16 件 + `pass B` 13 話 + `pass C` 13 話 + 第1層監査 12 話 + legacy 46 件）の検証を担う。非零セルは 106 個（古事記 37 話のうち評価可能 25 話にプロファイルあり、平均 1.54 次元/話；legacy は 30 話・166 セル）。
* **指標と帰無モデルの設計**: 単一モチーフのみの 9 話では相手が同一次元で最大値をとれば被説明率が 100% へ飽和するため（単一モチーフ平均 86.06%、複数モチーフ平均 51.04%、適格親なし 14 話）、主エンドポイントを「適格な親候補集合上でのコサイン分布で規準化した最良一致 z 値（校正済み類似度）」と事前登録し、親候補ベクトルの次元並べ替え帰無分布（`n_perm = 200`, シード 42）と対照した。

* 非校正コサイン（`p = 0.040`, `d = 1.83`）で認められる差は、ベクトルの疎性（1 話 1.54 次元）によって見かけの類似度が跳ね上がる性質によるもので、親集合の分布で z 規準化すると完全に消失する（`p = 0.498`, `d = −0.04`）。シード 42/43/44（p = 0.498 / 0.493 / 0.517）や距離・閾値・親上限の感度分析でも主系での有意性は一度も得られず、ノード別 FDR（25 話）でも有意は 0 話である。

### 3.2 評定信頼性および語彙独立性（pass A / B / C）

| 比較ペア | 対象セル | Krippendorff α | 完全一致率 | ±1 以内 |
| :--- | ---: | ---: | ---: | ---: |
| `pass A vs pass B`（同一語彙・37 話 0 埋め） | 555 | 0.755 | 95.68% | 98.38% |
| `pass A vs v17 legacy`（37 話） | 555 | 0.498 | 82.88% | 93.51% |
| `L1 監査 vs v16 凍結値`（12 話 × 10 次元） | 120 | 0.689 | 71.67% | 89.17% |

* 同一 13 話上での α は、同一語彙間の `0.954` から固有名詞・書名・個別神名を排した中立定義 `pass C` への変更により **0.220 低下**して `0.734` となった（許容下限 0.667 は上回るが、完全一致率は 97.44% から 80.00% へ低下）。同一語彙での高再現性には語彙例示への追従が含まれることが定量化され、同時に `pass C` 差し替え検定（`L2-PASSC-SENS`: p = 0.751, d = −0.65）でも第2層無信号の結論が再確認された。

## 4. 方法論的寄与・限界・再現性

* **事前登録と多数分岐の CI 管理（ADR 0002 / `src/check_registry.py`）**: 全 12 枝のうち仮説検定 3 枝（`L2-15D`, `L1-75D`, `L2-PASSC-SENS`）に対し、α = 0.05 の Holm 第 1 しきい値 0.0167 と必要最小置換回数 59（設定 `n_perm = 200`）を CI で自動検査する。`src/sim_swarm_review.py` が示す通り、共有バイアス b = 0.10 の下で評定者を R = 1 から R = 10 へ増やしても RMSE は 0.141 → 0.105 に留まり消去できない一方、登録なき 144 本の探索分岐では偽陽性率が 0.9994・最小 p 中央値 0.0048 に達する。ゆえに本リポジトリは凍結事前登録（タイムスタンプ検証 `src/check_prereg.py`）と登録数連動型 Holm・置換回数検査を強制している。
* **主な限界**: (1) 評価可能 25 話・1.54 次元/話の標本では小効果まで棄却できない（「信号の不存在の証明」ではなく「情報を認めない」）、(2) 評定主体はいずれもテキスト証拠を伴う単一 LLM セッション系であり人間専門家間の再現性ではない、(3) 緯度経度・実効年代は粗い近似を含む。
* **完全再現性**: `make clean && make all && make network && make determ && make registry` で、全 12 出力ファイルがシード 42 のもとビット単位で決定論的に再現される（不一致 0 件確認済み）。また本書・英語要約・方法論報告の全数値は `src/verify_doc.py` により JSON 出力と機械照合される。
