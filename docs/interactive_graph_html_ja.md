## 🗺 地理座標モードの世界地図背景

「地理座標」表示モードに、**Natural Earth 1:110m**（パブリックドメイン）の世界地図を
背景として表示します。タイル地図などの外部サービスは使わず、**陸域・国境を投影済み SVG
パスとして HTML に埋め込んでいる**ため、オフライン `file://` 表示の完全自己完結性を
保ったまま地図表示できます（外部参照の増減はゼロ）。

* **ノードと地理の対応**: 地図とノードは**同一のメルカトル投影パラメータ**
  （`derived/world_land.json` の `projection`、テンプレートの `geoX`/`geoY` が参照）で
  配置されるため、ノード座標と地図は必ず一致します。配置基準座標（baseX/baseY）は投影値と
  厳密一致、表示座標は v17 原本の Collision Relaxation（密集クラスタの可読性のための
  局所展開、最大 20px 程度）に従います。
* **トグル**: ツールバーの「🗺 地図背景」で ON/OFF（既定 ON、リセットで復元）。
* **出典表記**: 凡例に「Natural Earth 1:110m（パブリックドメイン・HTML埋め込み・通信なし）」。
* **再現**: `src/extract_world_map.mjs` が npm `world-atlas` パッケージの TopoJSON から
  `derived/world_land.json` を生成します（開発時のみ必要。配布 HTML に依存関係なし）。

```bash
npm install world-atlas topojson-client   # 作業用。生成物だけコミットする
node src/extract_world_map.mjs node_modules/world-atlas/land-110m.json \
    node_modules/world-atlas/countries-110m.json derived/world_land.json
```

## 🐫 交易路オーバーレイ（スイムレーンの半透明の帯）

スイムレーン表示に、**交易史・考古学遺物に基づく中継交易ルート**を「半透明の薄い帯」として

セクター間の**交易による接続性**を大雑把に把握するためのものです。

* **帯の読み方**: 各レーン（セクター）に沿う半透明の帯＝該当セクターが交易圏に参加、
  レーン間の縦の軟帯と中継点ドット＝セクター間の中継接続。ラベルはルート名、
  帯の横幅はおおよその存続期間です。**表示は学界で広く確認されている交易圏の近似**であり、
  厳密な経路・年代の断定ではありません（帯クリック時の詳細にも注記）。

  隣のセレクトで時代絞り込み（全時代／ウルク拡大期〜初期青銅器／ディルムン・メルッハ期／
  殷商時代／アマルナ〜末期青銅器／**弥生時代（前10世紀頃〜3世紀中頃・最新推定）**／
  サカ・クシャトラパ・サータヴァーハナ）。
  ホバーでツールチップ、クリックでインスペクタに詳細（交易品・結ぶセクター・拠点と証拠）。
* **収録ルート（12 本）**: ラピスラズリの道／琥珀の道（バルト→地中海→西アジア）／
  ディルムン・マガン・メルッハの中継交易／殷商と中央アジアの交易路（馬・玉・青銅）／
  アマルナ時代の外交・贈答交易圏／シルクロード（西域経由・メソポタミア経由を含む）／
  南回りインド海路（ペルシア湾方面含む）／東西インド横断路（中持ち・中継交易）／

## 考察：交易路からみた古事記以前のユーラシア接続性（可視化の解釈）

交易路オーバーレイ（12 ルート）を統合すると、次のことが言える。すなわち
**古事記（712 年）の成立以前——実際には紀元前 4〜3 世紀頃にはすでに——、
ユーラシアの東（日本列島）から西（地中海世界）まで、地域交易網がリレー式に
重なり合った連鎖が成立し、物品・情報が「流通可能な」状態にあった**。
可視化した帯は、まさにその「可能性のトポロジー」である。ただし次の 3 点の
正確化が必要である。

1. **「1 本の道」ではなく「中継ネットワークの連鎖」**: 帯が示すのは各セクターの
   参加と中継点であり、単独の商人が大陸を端から端まで移動したわけではない。
   ラピスラズリはバダフシャーン→イラン→メソポタミアと手を変え、琥珀は
   北欧→エーゲ→エジプトと段階的に運ばれた。全体接続性は「最も弱い環」で決まる。
2. **接続の濃淡は時代による**: 連鎖が明確に途切れないのは戦国〜ローマ時代
   （前 4 世紀〜後 3 世紀）以降。それ以前はウルク圏⇄ディルムン・メルッハ圏⇄
   アマルナの外交圏⇄殷⇔中央アジア圏という広域圏どうしの部分的な重なりの段階で、
   前 3 世紀の明刀銭が北部九州まで到達した頃に東端〜西端の鎖が実質的に完成する。
3. **「到達可能性 ≠ 移動量」——ただしゼロではなかった**: 実際の流量は別問題だが、
   端から端まで動いたことは物証がある（例: ラピス＝バダフシャーン→ウル・スーサ
   約 2,500km、バルト琥珀→ミケーネ・エジプト約 3,000km、明刀銭・前漢鏡＝
   燕・楽浪→北部九州約 1,500km、ローマ金貨・ガラス＝地中海→アリカメドゥ約 5,000km）。

### 本リポジトリの 2 層構造との対応

* **交易路の帯**（12 ルート）＝ 物理的移動が**可能だった**経路の層（可能性のレイヤー）
* **モチーフ伝播グラフ**（597 エッジ）＝ **実際に移動した**情報・モチーフ断片の実証層

実際の移動は距離と時間差つきで記録されている。全グラフで最長の伝播エッジは
**インド（仏教）→北欧 8,451 km**（directed_transmission）、6,000km 超のエッジが
22 本ある。古事記ノードへの親エッジの例として、中国→K1-02（2,982km・Δt=512 年・
重み 0.949）、東南アジア→K1-01（4,078km）、シベリア→K1-01（4,474km・Δt=1,212 年）
が確認できる。一方、K1-05（禊祓と三貴子）の先行被説明率は 70.7% で、残りは
局所生成・未説明である——つまり移動は起きたが、情報は距離と時間で減衰・変換される
（エッジの `transforms` 列）。これが「実際にどの程度移動したか」の定量的な答えになっている。

### 留意点

* 帯は学界の知見の**近似**である（琥珀の道のメソポタミア到達・南西諸島路・北方路には
  暫定注記あり）。
* 交易路の帯の描画は〜3 世紀頃までだが、古墳・飛鳥時代（250–710 年）の接続は
  倭の五王・遣隋使などによりさらに濃密であり、「奈良時代以前」という命題はむしろ強まる。
* 「ユーラシア全域」は連鎖の弱い環の範囲の話であり、シベリア内陸等は対象外。
* 以上の数値（8,451km・22 本・70.7% 等）は `tests/test_interactive_html.py` が
  埋め込み DATA とドキュメント記載の一致を照合している。

## 再生成と決定性

```bash
# 1) 原本 HTML から埋め込み DATA を抽出（原本更新時のみ。出所 SHA-256 を記録）
python3 src/build_interactive_html.py --extract <path-to-v17-html>

# 2) 最新データを統合して HTML を再生成（要 numpy なし。標準ライブラリのみ）
make interactive    # または python3 src/build_interactive_html.py
```

同一入力なら生成物は常に同一（タイムスタンプ非埋め込み・キー整列済み JSON）。
`.gitignore` は HTML を原則除外しているが、本ファイルとテンプレートのみ例外・追跡する。

## ブラウザで開く方法（ローカル動作の保証）

この HTML は**外部参照が 1 つもない完全自己完結文書**です（CDN・画像・fetch・XHR・iframe・
http(s) URL すべてゼロ。`http://www.w3.org/2000/svg` は通信しない XML 名名空間識別子のみ）。

* ダウンロードしたファイルを **Chrome に直接ドラッグ＆ドロップ**（またはダブルクリック）すれば、
  **オフラインの `file://` 表示でそのまま動作**します。
* 404 が表示された場合、表示されているのはこの HTML ではなく**取得元 URL のエラーページ**
  （保存された 404 ページ）である可能性が高いです。正しい取得経路:
  1. GitHub の blob ページ右上の「Download raw file」
  2. リポジトリの ZIP ダウンロード（`docs/interactive/graph_network_atlas.html` を含む）
  3. `git clone` 後の `docs/interactive/graph_network_atlas.html`
