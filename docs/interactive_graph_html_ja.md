# グラフネットワーク確認用インタラクティブ HTML（2026-11-27）

`docs/interactive/graph_network_atlas.html` は、**このリポジトリの最新の凍結データだけ**を
入力に、古事記神話とユーラシア神話の対応グラフネットワークを人間が確認するための
自己完結のインタラクティブ HTML です。外部 CDN・外部 API・ネットワーク接続を一切使いません。

## 目的

* 297 ノード・第 1 層エッジ・層構成・表示出所・乖離台帳を、1 つの画面で機械的に突き合わせる。
* ADR 0003（表示混成の注記運用）の結果——表示被説明率と表示 L1 辺からの再計算が
  閾値 0.01 を超えて乖離する話——を、改変せずに可視化する。
* 第 2 層 R01-R15 評定（証拠引用つき）と L1 信頼性の独立再評定を、ノードごとに確認できる。

## 再構築するエッジとその性格

エッジは v17 埋め込みグラフのコピーではなく、**v18 エンジンで凍結行列から再構築した**ものです。

* **L1 主解析**（`config/analysis.json` の `engine.primary`、校正済み類似度 z）:
  2026-11-27 構築時点で 695 本。しきい値・親数・距離上限はすべて設定ファイル由来。
* **L1 参考**（`engine.reference_v17_compatible`、v17 互換コサイン）: 同 491 本。
  凍結 v16 の in_deg 合計（494 本相当）とは一致しません。v17 の手書き変換ペア
  （TRANS_PAIRS、重み 0.10–0.15）はリポジトリに追跡されていないため、参考再構築は
  v16 本来の辺集合と同一ではありません（本 HTML の台帳列で per-node の次数差を確認可能）。

## 既知の制約（HTML 内「データと注記」と同じ内容）

1. **純 L2 接続辺は非表示**。v17 埋め込みグラフの期待値は 297 ノード / 597 エッジで、
   うち v16 L1 494 本 + 純 L2 103 本相当（597 − 494）と整理されているが、純 L2 の
   辺台帳はリポジトリに追跡されていない（v17 パッケージは `vendor/` 配下・コミット対象外）。
   アンカーノード（LP01–LP16）の第 2 層接続も同様に現れません。
2. **表示値は改変しない**（ADR 0003）。乖離台帳 21 話は赤リングと「乖離」列で識別できます。
3. **R01–R15 の語彙ラベル**は v17 パッケージ側の定義であり、リポジトリには次元 ID と
   水準（0 不在〜3 中心的）のみ追跡されています。
4. この HTML 自体は生成物です。`derived/html_embedded_v17_audit.json` の方針
   （annotate_with_derived_audit）に従い、凍結入力は変更せず、再構築結果を注記として提示します。

## 確認画面

| タブ | 内容 |
| :--- | :--- |
| 地図 | 経緯度配置。ノード色 = 地域（19）、形 = 種（ユーラシア／古事記／アンカー） |
| 時系列レーン | 19 地域レーン × t_eff。v17 のスイムレーン構成に対応 |
| グラフ | 力导向配置。構造的な近接関係の確認用 |
| L2行列 | 古事記 37 話・アンカー 16 件 × R01–R15 の水準マトリクス（証拠はホバー／詳細） |
| 台帳 | 全 297 件のソート可能な一覧（表示出所・被説明率・乖離・v16 次数・再構築次数） |

ノードクリックで、表示監査・凍結 v16 統計・L1 モチーフ・L2 評定（証拠引用）・
接続エッジを右パネルに表示します。

## 再生成と決定性

```bash
make interactive    # または python3 src/build_interactive_html.py（要 numpy / pandas）
```

同一入力なら生成物は常に同一（タイムスタンプ非埋め込み・キー整列済み JSON）。
UI・操作ロジックは `src/interactive_atlas.template.html.tmpl` にあります。
なお `.gitignore` は HTML を原則除外していますが、本ファイルのみ例外として追跡します
（ユーザー要望による人間確認用成果物。再生成手順は本ドキュメントのとおり）。
